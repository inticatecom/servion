# Servion

A Docker container management interface primarily for game-server management.

The panel is designed to provide end-users an experience that requires little to none tech-knowledge so you can just get to managing and creating game-servers.


## Developers
Guides for developers & contributors who will be directly interacting with the project's codebase.

### .NET Execution
Commands within the .NET application are executed via Just. Similarily to Node.js, you can run commands with `just [command]`. All commands can be listed with just the name, `just`.

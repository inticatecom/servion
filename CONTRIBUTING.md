# Contribution Guidelines

We accept contributions from all individuals. We only ask that you be respectful of the project and understand that it took a long time to develop and lots of developers have put countless hours into the development of the project.

As always, all contributions will be reviewed by official maintainers and leave comments for any changes that may be required.

Thank you for any contributions made.

## Translations

Translation contributions are currently private, planned to be made public in the future. For now if you want to contribute to translations, please contact an official maintainer directly or open an issue with the request information including your requested translation language.
